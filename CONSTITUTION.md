# CONSTITUTION — Asistente Celsia

La constitución de este proyecto (propósito, alcance, stack, estructura, convenciones,
flujo de trabajo e historial de decisiones) vive en
[`.specify/memory/constitution.md`](.specify/memory/constitution.md), que es donde la
espera GitHub Spec-Kit, la herramienta con la que se escriben las especificaciones de
[`specs/`](specs/).

Este archivo solo existe para que el estándar del curso la encuentre en la raíz. **No
duplica nada**: cualquier cambio arquitectónico, tecnológico o de proceso se escribe en
el archivo de arriba, en el mismo commit que el cambio.
